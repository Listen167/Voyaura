# 码道在 Voyaura 项目开发中的应用总结

团队在 VS Code 中通过华为码道插件开展开发辅助工作。《码道使用情况.docx》保留了四类场景的部分交互截图，原件作为参赛过程附件提交。

| 场景 | 在本项目中的用途 |
| --- | --- |
| 环境搭建 | 辅助梳理前后端依赖、运行环境和安装步骤，便于开发环境配置与复现。 |
| 代码检查 | 辅助阅读项目代码、定位需要检查的实现细节，为开发者复查与测试提供线索。 |
| 服务器购买准备 | 辅助梳理云服务器选型与购买流程，整理部署需要准备的环境和资源。 |
| 设计方案 | 辅助梳理旅行规划、城市记录与小曦交互的功能组织，形成可逐项实施的设计思路。 |

表内场景对应 Word 原件的小节。源码、部署文档和测试结果用于说明产品目前可运行的功能；插件交互的过程证据以原件中的截图为准。
