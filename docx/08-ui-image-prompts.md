# Image 2 UI 样式图提示词

这些提示词用于生成 Voyaura 的视觉方向参考图，不要求模型生成可直接开发的代码。建议先各生成 2 至 4 个版本，再选择一组作为前端精修依据。

## 统一视觉方向

- 产品：Voyaura，中国地图优先的私人旅行记忆与摄影创作应用。
- 气质：明艳、成熟、富有旅行感；兼有复古胶片档案和现代摄影工作台。
- 色彩：珊瑚红、亮黄、孔雀绿、湖蓝作为重点色，用深墨色和纸张白平衡；避免整页米黄或单一棕色。
- 元素：中国地图、城市点亮、照片底片、相机参数、路线、邮戳、明信片边缘，但保持界面清楚可用。
- 产品界面而非营销落地页：不要大 Hero，不要装饰性卡片套卡片。

## 网页端提示词（16:9）

```text
为一款名为 Voyaura 的中国私人旅行摄影应用设计高保真桌面网页 UI，16:9，1440×900。第一视觉信号是可交互的中国地图，已旅行城市用珊瑚红和亮黄色摄影光点标记，并有细致旅行路线。左侧是克制的垂直工具导航，中间是大幅地图与真实旅行照片，右侧或底部是“我与这座城市”的照片档案和 Vlog 时间线。加入一个专业图片创作工作台：左侧生成历史，中间原图与风格图滑动对比，右侧显示风格、城市记忆、提示词、收藏、下载和删除操作。整体融合现代摄影编辑器、复古胶片、明信片邮戳和中国旅行图册气质；色彩明艳但成熟，珊瑚红、亮黄、孔雀绿、湖蓝搭配深墨色与干净纸张白。信息密度适中，网格清晰，方正小圆角，真实旅行摄影，高级中文产品 UI，避免营销首页，避免大标题 Hero，避免卡片套卡片。请输出完整浏览器视口的产品界面样式图。
```

## 手机端提示词（9:16）

```text
为 Voyaura 中国私人旅行摄影应用设计高保真手机 UI，9:16，390×844。首屏以中国地图为主要内容，城市点亮像明艳的胶片曝光点，显示当前城市、旅行足迹和一张可上拉的城市记忆抽屉；底部为五项图标导航，并有“小曦”旅行伙伴的轻量入口。另一核心状态展示手机图片创作工作台：顶部大幅原图与生成图触摸滑动对比，中部横向生成版本胶片条，下方依次是城市记忆、摄影风格与可编辑提示词，底部固定收藏、下载、删除操作栏。视觉融合旅行摄影、复古胶片边框、路线图、邮戳与现代移动端编辑器；使用珊瑚红、亮黄、孔雀绿、湖蓝、深墨色和纸张白，明艳、温暖、成熟，不幼稚。适配单手操作，文字层级清楚，按钮和触控区域真实可用，不要营销落地页，不要夸张 Hero，不要卡片套卡片。请输出完整手机屏幕产品界面样式图。
```
