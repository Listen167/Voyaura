# 界面与响应式设计

## 第一视觉

应用打开后直接进入全屏中国地图，不设置营销落地页。地图是内容和导航本身。

## 视觉语言

从 `Emo_Agent` 延续：

- 纸张纤维与轻微扫描颗粒；
- 胶片边缘、暗房显影和印章动作；
- 打字机字体与克制的手写标题；
- 小曦的向日葵黄、叶片绿和柔和天蓝。

Voyaura 调整：

- 地图区域保持清晰、安静、无装饰边框；
- 珊瑚红用于到访和记录，琥珀黄用于小曦，青绿色用于定位；
- 避免整页米黄色、整页深蓝或大量嵌套卡片；
- 图标按钮使用 Lucide 图标并提供 tooltip；
- 动效尊重 `prefers-reduced-motion`。

## 手机端

- 地图占满视口。
- 顶部保留定位和小曦入口；搜索在 POI 功能接入时加入。
- 底部是地图、行程、记忆、创作、我的五个主入口，小曦使用独立浮动入口。
- 城市记忆使用可拖动底部抽屉。
- 拍照、录像和点亮城市操作适配拇指触达区域。

## 桌面端

- 左侧窄导航栏。
- 中间为地图主画布。
- 右侧按需打开城市记忆、小曦聊天或行程编辑器。
- 图片工作台使用原图和生成图双栏对比。

## 首个界面验收

- 375x812、768x1024、1440x900 均无文字重叠和横向溢出。
- 无高德 Key 时显示带错误码和修复建议的地图配置状态，不使用不准确的示意中国地图。
- 有 Key 时中国地图成功加载并可定位。
- 手机底部导航不遮挡地图抽屉内容。
