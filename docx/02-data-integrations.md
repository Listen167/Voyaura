# 数据与第三方接入

## 高德地图

| 能力 | 计划使用方式 | 数据落库 |
|---|---|---|
| 中国底图 | 高德 JS API 2.0 | 不缓存瓦片 |
| 城市边界 | DistrictSearch / 行政区 API | `adcode` 和必要的展示缓存 |
| 定位 | 浏览器 Geolocation + 高德坐标转换 | 用户确认后的定位证据 |
| 地理编码 | 高德 Web 服务 | 地址、经纬度、`adcode` |
| POI | 高德 Web 服务 | POI 快照、来源和查询时间 |
| 市内路线 | 高德 Web 服务 | 驾车、步行、公交地铁的距离、时长、费用和步骤快照 |
| 铁路 | 携程/同程等正式合作接口 | 车次、车站、时间、席别、价格、余票来源与查询时间 |
| 航班 | Amadeus 开发验证；国内授权 Provider 上线 | 航班、机场、时间、舱位、价格、余量来源与查询时间 |
| 天气 | 高德天气，必要时增加和风天气 | 实况/预报快照与查询时间 |

生产环境不得使用来源不明的中国行政边界 GeoJSON，也不抓取或重新分发高德瓦片。

当前前端已经使用高德 JS API 2.0、`DistrictLayer.Country` 和 Loca 2.0。后端通过 Web 服务完成 WGS-84 转 GCJ-02、逆地理编码和行政区查询。前端 Key 与 `securityJsCode` 只放在 `web/.env.local`；Web 服务 Key 与可选数字签名私钥只放在 `api/.env`。

城市地点发现使用高德 Web 服务 v5 `place/text` 与 `place/detail`。前端只提交关键词和六位城市 `adcode`，后端返回高德来源、查询时间、GCJ-02 坐标及可用的评分、营业时间等字段；缺失字段保持为空，不推测价格或开放状态。导航使用 `https://uri.amap.com/marker` 官方链接并明确 `coordinate=gaode`。

路线分为高德负责的市内/接驳路线和独立跨城 Provider。高铁、普通火车和飞机不能仅靠高德路线结果代替票务数据；铁路不调用 12306 未公开网页接口，航班开发期可使用 Amadeus，生产环境按国内覆盖选择授权合作方。详细选择和所需凭证见 `10-route-provider-strategy.md`。

若 Web 服务 Key 在控制台开启“数字签名”，必须配置 `VOYAURA_AMAP_WEB_PRIVATE_KEY`；不使用数字签名时应在控制台关闭该选项。当前本地 Web 服务 Key 返回 `10007 / INVALID_USER_SIGNATURE`，所以真实点亮写库仍需先修正控制台签名设置。

## 城市点亮

```text
请求定位 → 检查精度 → 坐标转换 → 逆地理编码 → 获取 adcode
         → 用户确认城市 → 创建 CityVisit → 允许添加照片/Vlog/日记
```

第一版只在用户主动操作时定位。持续后台轨迹需要原生权限和单独的隐私设计。

## 小红书、大众点评和门票

- 小红书第一版支持用户主动粘贴链接、保存摘要和生成发布草稿。
- 不把未授权爬虫或 Chrome 自动发布作为核心依赖。
- 大众点评数据需正式开放平台或商务授权；未授权阶段使用高德 POI 并提供外部跳转。
- 门票价格必须附来源、币种和查询时间；第一版跳转景区官网或 OTA。
- 任何购买、预订或公开发布都必须由用户最终确认。

## 城市知识来源

优先级从高到低：

1. 文旅局、景区官网和公共交通官方信息。
2. 地图与天气服务的结构化数据。
3. 用户主动收藏或导入的公开内容链接。
4. 用户自己的照片、Vlog、日记和评分。
5. AI 的解释与组织，不作为事实来源。

## 风格图片

- `gc-minimal-zine-poster` 当前公开版本为 v0.3.1，调用名为 `gc-minimal-zine-poster-v0-3`。
- 它采用 MIT 许可，集成时保留许可证和版权声明。
- 它提供 Prompt 与质量系统，不提供 ComfyUI、模型或推理服务。
- 中文标题、日期和地点由应用后期排版，不依赖图片模型正确生成文字。
