# 与四张参考图的差异与保留项

以下是本轮有意保留的项目，不属于已完成能力。当前已采用四图的核心排版和构图，配色继续使用93659b9。

| 参考细节 | 本轮处理 | 原因／当前事实 |
|---|---|---|
| 首页暖光厦门、花枝、西湖近亭和单只熊猫 | 继续使用已有授权摄影，调整布局与裁切 | 现有图片主体不同，没有把整张参考图抠成产品实景照片 |
| 写实纸纹、水彩山脉和远树 | 保留既有暖纸底、等高线与手帐图形 | 装饰图生成请求返回503，无可用产物；不把未生成的资产宣称已落地 |
| 规划右侧具体广州山水与天际线 | 保留原城市标签及既有通用图纹，选有已授权照片的目的地时显示对应灵感图 | 通用插画不代表该城市实景；没有把厦门摄影标为广州 |
| 规划参考只展示三块条件 | 保留全部偏好、地点、授权和更细安排 | 这些是实际工作流所需字段；不能为截图简洁而丢失输入和授权 |
| 左侧长篇章节说明 | 使用简洁章节编号对应实际输入组 | 避免重复解释，01旅行想法、02基本安排、03旅行偏好 |
| 故事右侧地图路线与定位点 | 使用既有等高线装饰，无虚构访问路线 | 尚无真实轨迹；布局装饰不应冒充走过的路线 |
| 故事“第1天抵达/第2天漫游”时间线 | 不添加 | 用户所选日期范围不等于已发生事件，实际记录仍从授权来源读取 |
| 故事相片框 | 有对应城市许可摄影时标注“目的地灵感图”；没有时显示已有手帐插画，注明“所选城市” | 不凭空生成用户照片或给错误城市配实景 |
| 创作页灯、相框、镜头、木架和实物暗房背景 | 保留当前纸白标题区，采用深绿照片工作区 | 装饰图生成失败，现有本地没有相应授权资产 |
| 创作左边三张缩略作品及上下箭头 | 空态仅保留胶片孔边装饰与一张标明来源的参考摄影；真实历史列表保持原样 | 空档案作品数为0，没有可切换个人作品；不放无行为的假按钮 |
| 创作下部的三个档案快捷入口、使用指南、服务状态 | 保留原来在“我的档案”中的位置 | 参考图混入档案页内容，用户未要求改变这些入口的语义 |
| 影像生成和在线地点服务 | 保留原有未连接状态、授权与错误处理 | 本轮是视觉迭代，没有开通或伪造外部服务 |
| 我的档案、旅行足迹、城市记忆书架 | 延续93659b9 | 本轮新增三图对应规划、故事、创作，与先前首页共四个改稿对象 |
| 移动端无对应参考图 | 沿用原响应式交互，按可读性调整排列 | 四入口2×2、表单单列、创作选图优先；底部导航、焦点和确认机制保留 |

品牌邮戳只作为宽屏装饰，没有添加EST年份、到访章、用户身份或邮政记录。
